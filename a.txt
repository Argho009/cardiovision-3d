import sys, re, json, pandas as pd
from sklearn.linear_model import LogisticRegression
from sklearn.model_selection import StratifiedKFold, cross_val_predict
from sklearn.metrics import accuracy_score, precision_score, recall_score, f1_score, roc_auc_score
from sklearn.preprocessing import StandardScaler
from sklearn.pipeline import make_pipeline

path = sys.argv[1]
df = pd.read_excel(path) if path.lower().endswith(("xlsx", "xls")) else pd.read_csv(path)
df.columns = [re.sub(r"[^a-z0-9]", "", str(c).lower()) for c in df.columns]

# viewer key -> normalised column name (edit if your header differs)
FEATS = {"age": "age", "bp": "bp", "pr": "pr", "fbs": "fbs", "ldl": "ldl", "rwma": "regionrwma",
         "htn": "htn", "dm": "dm", "cp": "typicalchestpain", "ste": "stelevation",
         "ti": "tinversion", "lvh": "lvh"}
TARGETS = {"cad": "cath", "lad": "lad", "lcx": "lcx", "rca": "rca"}
assert not set(FEATS.values()) & set(TARGETS.values()) | {"cath"} & set(FEATS.values()), "target leakage"

YES = {"y", "yes", "1", "true", "cad", "stenotic", "present", "abnormal"}
def num(s):
    if pd.api.types.is_numeric_dtype(s): return s.astype(float)
    return s.astype(str).str.strip().str.lower().isin(YES).astype(float)
def label(s):
    y = num(s)
    return (y >= 50) if y.max() > 1 else (y > 0)   # percent stenosis -> >=50%

X = pd.DataFrame({k: num(df[c]) for k, c in FEATS.items()})
X = X.fillna(X.median())
cv = StratifiedKFold(5, shuffle=True, random_state=0)
out = {"bias": {}, "features": {k: {"w": {}} for k in FEATS}, "metrics": {}}
for t, col in TARGETS.items():
    y = label(df[col]).astype(int)
    print(t, "positives:", y.sum(), "of", len(y), "(check this matches the dataset)")
    pipe = make_pipeline(StandardScaler(), LogisticRegression(C=0.5, max_iter=2000))
    p = cross_val_predict(pipe, X, y, cv=cv, method="predict_proba")[:, 1]
    yh = (p >= .5).astype(int)
    out["metrics"][t] = dict(acc=accuracy_score(y, yh), precision=precision_score(y, yh),

    print({k: round(v, 3) for k, v in out["metrics"][t].items()})
    pipe.fit(X, y)
    sc, lr = pipe[0], pipe[1]
    out["bias"][t] = float(lr.intercept_[0])        # log-odds for an average patient
    for i, k in enumerate(FEATS):
        out["features"][k].update(mean=float(sc.mean_[i]), std=float(sc.scale_[i]))
        out["features"][k]["w"][t] = float(lr.coef_[0][i])   # per 1 SD; SHAP = w * z

# Build prompt: 3D Coronary Risk Visualization and Prediction (Hackathon Track A)

## 1. Goal

Build a web application that predicts overall coronary artery disease (CAD) status and stenosis status of the LAD, LCX and RCA from patient clinical data, then maps those predictions onto an interactive 3D heart/torso model. A clinical dashboard sits beside the 3D canvas and explains each prediction with SHAP.

Dataset: the Extension of Z-Alizadeh Sani dataset (UCI id 411, also on Kaggle), about 303 patients with demographic, examination, laboratory, ECG and echo features. CAD here means at least 50% narrowing of a major coronary vessel.

Evaluation weights, which should drive your effort: predictive performance 30%, 3D visualization 25%, clinical interpretability 20%, system integration 15%, technical implementation 10%.

## 2. Hard rules

1. **No target leakage.** Exclude LAD, LCX, RCA and Cath from the input features for every target. Enforce this in code with an assertion and a unit test that fails if any of those columns reaches a model.
2. **Inspect before assuming.** Print the dataset header, dtypes, value counts for every target and the missing-value counts before writing preprocessing. Do not assume column names or how targets are coded (strings such as "Cad"/"Normal", 0/1, or percent stenosis). Document what you find in `docs/data_notes.md`.
3. **No leakage through preprocessing.** Imputation, scaling and encoding are fitted inside cross-validation pipelines, never on the full data before splitting.
4. **No overclaiming.** Region with RWMA is an input feature only. It does not locate a lesion. The 3D coronary arteries are schematic. The UI and report must say so.
5. **Disclaimer.** Every screen shows a persistent, visible notice: predictions are for decision support and educational purposes only and are not a substitute for formal diagnostic imaging or clinical judgement.
6. **Reproducible.** Fixed seeds, pinned dependencies, one command per stage (see section 8).

## 4. ML pipeline

**Data.** `download_data.py` fetches the dataset (try `ucimlrepo.fetch_ucirepo(id=411)`, fall back to a documented manual download path). Parse targets according to what you found in the inspection step. For vessel columns that hold percent stenosis, positive means 50% or more; for coded or string labels, document the mapping.

**Features.** Use demographic, clinical examination, ECG, laboratory and echocardiographic columns. Encode binary and categorical fields (one-hot for multi-level), median-impute numerics, most-frequent-impute categoricals. Keep original feature names recoverable so SHAP output maps back to human labels from `features.yaml`.

**Targets.** Four independent binary classifiers: `cad`, `lad`, `lcx`, `rca`. Note class imbalance per target in the report (LCX and RCA are likely the hardest).

**Models and selection.** Candidates: L2 logistic regression, random forest, gradient boosting (XGBoost or LightGBM). Hold out a stratified 20% test set once, never touched during tuning. On the remaining 80%, use repeated stratified 5-fold cross-validation (at least 5 repeats) with hyperparameter search inside it. Pick the best model per target by cross-validated ROC-AUC, with ties going to the simpler model. With only about 300 records, prefer simple, regularized models and say why.

**Calibration.** Calibrate probabilities (sigmoid, or isotonic if sample size allows) inside the training procedure. Report Brier score and a reliability plot. The UI shows probabilities, so calibration matters.

**Metrics.** For each target report on the held-out test set and in cross-validation: accuracy, precision, recall, F1, ROC-AUC, PR-AUC, Brier score, confusion matrix at threshold 0.5, and bootstrap 95% confidence intervals for the test metrics. Also report a sensitivity-oriented threshold and what it costs in precision. Save everything to `artifacts/metrics.json` and figures (ROC, PR, calibration, confusion) to `artifacts/figures/`.

**Explainability.** `explain.py` computes SHAP values: TreeExplainer for tree models, LinearExplainer for logistic regression. Provide per-patient attributions in the original feature space (aggregate one-hot columns back to the source feature) and a global mean-absolute-SHAP ranking per target. Verify with a test that the base value plus the sum of attributions reproduces the model output.

**Export.** `export.py` saves, per target, the fitted pipeline (joblib), the SHAP background sample, and a `model_card.md` with intended use, data, metrics, limitations and the leakage policy.

**Dashboard (beside the canvas).**
- Overall CAD status (predicted label and probability) and the three vessel probabilities, each with a bar and the same color ramp as the 3D view.
- Patient input form generated from `/schema`, grouped (demographics, examination, ECG, laboratory, echo), with units and valid ranges, preset example patients, and instant updates (debounce about 150 ms).
- SHAP panel for the selected target: a diverging bar chart of the top contributors (red raises risk, teal lowers it), base value, and a plain-language sentence summarizing the top three drivers.
- Physiological breakdown: for each measurement, the patient's value, a reference range where one is well established, and its contribution to the selected prediction.
- Model tab: test-set metrics with confidence intervals, ROC curve, and calibration plot from `/metrics`.
- Loading, empty and error states that say what went wrong and what to do.
- Accessible: keyboard focus visible, sufficient contrast, responsive down to tablet width, light and dark themes.
